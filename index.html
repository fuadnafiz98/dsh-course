Inside DeepSeek Harness

A visual, click-through course on how dsh — the open-source agent harness from DeepSeek — is actually built. Every claim links to the real file. Every diagram node opens a detail panel. Start from Lesson 1 if you're new; jump anywhere if you're not.

The one-sentence version

DeepSeek Harness is not a program with plugins — it is a plugin tree that becomes a program. A YAML file lists packages; the Cordis framework mounts each one as a "fiber", lets them publish services on a shared context, and only activates a plugin once the services it injects exist. The agent loop, the tools, even the model adapter — all just rows in the tree.

How to use this course

  • Read in order the first time. Cordis (lessons 2–4) is the foundation; skip it and the rest reads like magic.
  • Click diagram nodes — every box opens a panel explaining the piece and linking to the implementing file at the pinned commit.
  • Follow the code chips (like this one) into GitHub to read the real implementation alongside the lesson.
  • Take the quizzes — they're retrieval practice, the thing that actually makes it stick.
  • Open "Go deeper" blocks only when the main path makes sense; that's where the sharp corners live.
  • Ask me follow-up questions — I'm your teacher; anything unclear is fair game.
Reading the repo itself

The canonical reading order the docs prescribe: docs/architecture.md first, then docs/cordis-primer.md, then a package README for whatever subsystem you're in. This course mirrors that order but slows down at every joint.
