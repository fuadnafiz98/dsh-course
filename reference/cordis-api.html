Cordis cheat sheet

The whole vendored framework distilled to its API surface. When you know these ~20 operations, you can read any plugin in the repo. Each links to the implementing source.

Context — vendor/cordis/src/context.ts

APIWhat it does
new Context()Create a root world; wires reflect/registry/events/logger and returns the proxy.
ctx.extend(meta?)Child context: prototypal inheritance plus own keys (e.g. a fiber's ctx.fiber).
ctx.isolate(name, key?)Child where service name resolves in a fresh realm — same name, different impl.
ctx.intercept(name, config)Merge config into every plugin under the child that uses service name.
ctx.mixin(name, entries)Provide derived properties on the context.
ctx.<name>Proxy read → resolve the service (throws if absent unless injected).
ctx.get(name)Strict read of the global store; undefined if absent — for optional deps.
ctx.provide(name, impl)Register an impl under a name — an owned effect (undone on unload).
ctx.fiberThe current fiber (set on the plugin's child context).

Plugins & fibers — fiber.ts · registry.ts

API / fieldWhat it does
ctx.plugin(plugin, config?)Mount a plugin → create a fiber. Accepts fn / {apply} / class.
ctx.inject(deps, cb)Run cb in a child ctx once all deps exist; re-runs if a dep is replaced.
static inject / injectPlugin's declared deps: ['a'] or {required:[], optional:[]}.
ctx.effect(fn)Run fn now; record its disposer on the fiber; runs in reverse on unload.
ctx.fork(config?)Mount a sub-plugin under the current fiber.
fiber.statePENDING → LOADING → ACTIVE | FAILED | UNLOADING → DISPOSED.
fiber.dispose()Unmount the plugin: unwind effects in reverse, unprovide services.
Fiber.update()Re-evaluate deps/config — wait more, reuse, or restart the fiber.

Services — service.ts

APIWhat it does
class X extends Servicesuper(ctx, 'x') registers the instance as ctx.x (auto-removed on unload).
Service.checkA service can gate whether a candidate may provide under its name.

Events — events.ts

APIDispatch
ctx.on(name, fn, opts?)Register a listener (owned by the fiber). opts: {prepend, global}.
ctx.emit(name, ...args)Fire all listeners, sync, not awaited — observability.
ctx.parallel(name, ...args)All listeners concurrently, await all.
ctx.serial(name, ...args)All listeners in order, awaited; truthy bails early.
ctx.bail(name, ...args)Sync; first truthy return wins.
ctx.waterfall(name, payload, next)Middleware chain — each listener gets (payload, next); must call next() to delegate.
ctx.on(name, key, fn)Scoped subscription — only events dispatched under that scope key.

Loader & Include — vendor/loader · vendor/include

PieceRole
LoaderPlugin that owns the entry tree — resolves specifiers, spawns fibers.
ctx.loaderThe mounted Loader service; ctx.loader.entries(), .await(), .create().
Include + cordis:includeParses a cordis.yml and applies patch lists; mounted as a builtin.
applyEntryPatchesThe pure patch algorithm (insert + id-targeted replace, last wins).
entry.update()Reapply an entry's config — drives fiber update/restart.

The invariants to memorize

  • Inject declares, fiber waits. Row order is meaningless; dependencies sequence mounting.
  • Every registration is an effect. Listeners, provides, child plugins — all undone on unload, in reverse.
  • Waterfall = next() or deny. Returning without next() short-circuits — that's the policy lever.
  • Contexts are a tree. extend/isolate/intercept create scoped worlds; services resolve per-realm.
