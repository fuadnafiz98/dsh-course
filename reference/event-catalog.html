Event catalog

Every named channel in the harness — session events (durable), agent events (live), tool events, LLM events, and Cordis internals — with its dispatch mode and who produces/consumes it. Filter below.

Session events — the durable log

Appended to the append-only log; the surface/model view derives from them. Owner: core/session/types.ts

EventSurface?Payload / purpose
turn/startno{ turn } — opens a turn before input is claimed
turn/endno{ turn, reason: TurnEndReason } — completed/aborted/blocked/error/max-tokens/interrupted/forked
step/startno{ turn, step } — opens a step (one model call + tools)
step/endno{ turn, step } — closes a step
request/headerno{ header: EpochHeader, reason } — call config + tools snapshot
request/contextnoRequestContext — provider/model/context-window route
system/messageyes (node 0)The rendered system prompt
user/messageyesHuman prompt or synthetic injection (source distinguishes)
developer/messageyesPer-step dev context (e.g. tool-registry diffs)
assistant/messageyes{ turn, step, message, stream, usage?, interrupted? } — settled step output
assistant/attemptno{ turn, step, stream } — a failed/cancelled attempt's stream
tool/callno{ callId, name, arguments } — the model asked
tool/resultyes{ message, error?, meta? } — the tool's model-facing reply + UI card payload
session/end-seedno{ inherited? } — the seed/live boundary in a forked log

Agent events — live, scope-keyed

Emitted on the agent's scope; observed by UI/SDK, never durable. Owner: core/agent/dispatch.ts + the loop.

EventModePurpose

agent/pre-stepwaterfallAdmit/reject/rewrite a step's admitted input — compaction, budgets
agent/requestwaterfallMutate the proposed call config before adapter binding
agent/request-errorwaterfallDecide retry vs. fail on a stream error (per adapter retryPolicy)
agent/turn-stoppingserialLast hook before a turn ends (continuation decisions)
agent/assistant-streamemitLive stream frames to listeners (UI)
agent/erroremit{ turn, step, error } reported at the live boundary
