Glossary

Every term in one place. Type to filter; each entry links to the source that owns the concept.

TermMeaningOwner
AgentOne driven session: the object that owns a session, an inbox, and a loop driver.core/agent
AdapterA plugin that translates between the canonical message vocabulary and one provider's wire protocol.llm/llm
assistant/attemptA durable event for a model call that committed no surface message — failed, retried, or cancelled.session/types
BundleA shipped composition unit: a cordis.patch.yml plus the plugin code its rows mount.bundle/
Capability seamA Definition/Provider/Consumer triple — the unit of swappability (e.g. shell, fs, subagents).docs/glossary
Context (ctx)The proxied service/event/plugin world every plugin receives.vendor/cordis
EffectA registered setup with a disposer, owned by a fiber, undone in reverse order on unload.fiber.ts
Entry / rowOne line of a config tree: id, name (module), config, disabled.loader
FiberThe runtime instance of one mounted plugin — its lifecycle, deps, and effect stack.fiber.ts
injectA plugin's declared service dependencies; the fiber stays PENDING until all required ones exist.registry.ts
Isolate / realmctx.isolate forks one service's resolution — same name, different impl, below a child context.context.ts
PatchA list of row edits (insert + id-targeted config replaces); last layer wins per row.include
PresetA named per-agent composition: plugins + prompt + tool subset mounted inside a scope.preset/
ProfileA named composition — an ordered bundle list plus the user's own patch layer.profile-boot
Scope / ScopeKeyAn opaque agent identity that routes registrations (down) and events (up).core/scope
SessionAn append-only SessionEvent log + its derived model-visible surface.core/session
SurfaceThe ordered, model-visible subset of session events — what the next request sends.surface.ts
StepOne model call plus the tool executions it requested.agent-loop
TurnOne "go" at user input — one or more steps, ending in a TurnEndReason.agent-loop
WaterfallMiddleware dispatch: each listener gets (payload, next) and must call next() to delegate.events.ts
ServiceA class that registers itself as ctx.<name> — auto-removed when its fiber unloads.service.ts
InboxQueued input in two lanes (next-turn, next-step) that the loop claims per step.inbox.ts
!!jsA cordis.yml tag: a JS expression evaluated at load against the boot context.include
$DSH_HOMEThe harness home (~/.dsh): profiles, sessions, home patch, .env.home-paths
