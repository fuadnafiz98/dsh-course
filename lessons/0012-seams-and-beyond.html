Capability seams & where things live

You've learned every mechanism. This last lesson zooms all the way out: the one pattern that repeats across the whole repo — the capability seam — and a guided map of which package owns which behavior, so you can navigate anything new by reflex.

The pattern, named

From the glossary: a capability seam is a triple —

  1. Definition — a Service contract (an abstract class + its ctx.* name),
  2. Provider — a plugin that registers an implementation, and
  3. Consumer — the code (often a model-facing tool) that uses it.

AGENTS.md is blunt: a seam is complete only when all three roles exist, and they're split only when they evolve independently. This is why packages/<group>/ so often contains three sibling packages: dsh-<thing> (definition), dsh-<thing>-local (provider), dsh-tool-<thing> (consumer tool).

Reading any new subsystem — the 4-question habit

For any package you haven't seen, answer these and you'll have it mapped in minutes:

  1. What's the seam? Find the ctx.<name> — grep super(ctx, ' in its definition package.
  2. Who provides it? Find the plugin(s) that register or construct the implementation.
  3. Who consumes it? Find who injects it — usually a dsh-tool-* or another service.
  4. Which events does it use? grep the package for ctx.on(' / ctx.emit(' — the event names reveal its extension points.

You now hold the map

Framework (Cordis) → composition (profiles/patches) → core spine (session, loop, tools, prompt, llm) → capability seams → surfaces. Every file you've seen slots into exactly one of those layers, and every feature is a plugin registering on a seam or a waterfall. That's the whole codebase's shape.

Go deeper: how you'd add a capability

Say you want a "database query" tool. Following the pattern: (1) author a Definition — dsh-db exposing ctx.db with a query contract; (2) a Provider — dsh-db-sqlite registering an impl; (3) a Consumer — dsh-tool-db registering a ToolDefinition on ctx.tools. Then add a row to a bundle patch so it's mounted. No loop changes, no core surgery — the seam pattern is designed so a new capability is three packages and a row, all discovered through the same machinery.
